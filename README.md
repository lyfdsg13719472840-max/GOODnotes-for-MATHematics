## Note Format

The notes in this repository are primarily stored as:

* **LaTeX source** (`.tex`) — searchable and editable source files
* **PDF** (`.pdf`) — compiled versions for convenient reading

The original notes were handwritten in GoodNotes and subsequently converted, reorganized, and typeset in LaTeX with AI assistance.

## Purpose

This repository is intended to serve as a long-term **personal mathematical knowledge base** rather than simply a collection of course notes.

As the archive grows, it provides a structured way to:

* quickly retrieve mathematical concepts studied in previous courses;
* review definitions, theorems, proofs, and standard techniques;
* trace connections between different areas of mathematics;
* maintain a searchable and reusable record of my mathematical studies.
